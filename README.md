# 🎛 Саундборд: телефон → Мак

Жмёшь кнопку или пишешь текст на телефоне — Мак говорит это вслух или играет звук.

## Запуск (на Маке)

```bash
git clone <этот репозиторий> && cd hello
node server.js
```

Нужен только Node.js (`brew install node`), зависимостей нет.

В терминале появится адрес вида `http://192.168.1.23:3000` — открой его на телефоне
(телефон и Мак в одном Wi-Fi). На айфоне: «Поделиться → На экран „Домой“» — будет как приложение.

## Что умеет

- **Свой текст** — пишешь что угодно, выбираешь голос (Milena — русский, Daniel/Samantha/Fred — английский) и скорость.
- **Фразы** — готовые кнопки («Оууу гадэм бро» и т.д.). Меняются в массиве `PRESETS` в `server.js`.
- **Звуки** — кидаешь любые `.mp3/.wav/.m4a` в папку `sounds/`, обновляешь страницу — появляются кнопки.
- **Стоп** — заглушить всё, что играет.

## PIN (чтобы соседи по Wi-Fi не баловались)

```bash
PIN=1234 node server.js
```

Телефон спросит PIN один раз и запомнит.

## Если голоса Milena нет

Системные настройки → Универсальный доступ → Устная речь (Spoken Content) → Системный голос → Управление голосами → скачай «Milena» (русский).
